# Hotel Management System

## Overview

This project is a Java-based Hotel Management System developed using Object-Oriented Programming (OOP) principles. The system allows customers to book hotel rooms based on their preferences, including room type, view availability, and VIP package options.

## Features

* Room booking system
* Single and Double room selection
* View and Non-View room options
* VIP package support
* Room availability checking
* Automatic room suggestion
* Price calculation based on room features
* Five-floor hotel structure with room numbering system

## OOP Concepts Used

* Encapsulation
* Abstraction
* Interfaces
* Inheritance

## Project Structure

* OOP.java → Main program
* Hotel.java → Hotel management and room search
* Room.java → Room implementation
* AbstractRoom.java → Abstract room definition
* Bookable.java → Booking interface
* Name.java → Client information

## Room Configuration

Each floor contains four rooms:

* Room 1 → Single + View
* Room 2 → Double + View
* Room 3 → Single + No View
* Room 4 → Double + No View

Example:

* Floor 1: 101, 102, 103, 104
* Floor 2: 201, 202, 203, 204
* Floor 3: 301, 302, 303, 304
* Floor 4: 401, 402, 403, 404
* Floor 5: 501, 502, 503, 504
